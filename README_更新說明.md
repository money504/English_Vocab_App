# English_Vocab_App 更新版

## 這次更新內容

1. 修正快速切換單字時，上一個例句仍可能播放的問題。
2. 使用 localStorage 記錄已出現的單字。
3. 同一輪會優先抽尚未出現的單字，全部出現後才重新開始。
4. 改用 Fisher–Yates 洗牌，隨機抽字較平均。
5. 改善 Safari、Chrome 與不同裝置的語音載入。
6. 離開頁面或切到背景時會停止語音。
7. 移除禁止手機縮放的設定。
8. 完成畫面的文字改得較符合「無壓力學習」定位。
9. 加入剩餘未出現單字數量提示。

## 使用方式

請把這個資料夾內的 `index.html` 覆蓋 GitHub 專案原本的 `index.html`。

原本的 `words_8A.js` 不需要修改，並且要和 `index.html` 放在同一層。

## 注意

瀏覽器會在 localStorage 中保存本輪已出現的單字。
清除瀏覽器網站資料後，學習紀錄會重新開始。
