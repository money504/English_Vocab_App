# English_Vocab_App：學習紀錄與單字搜尋版

## 新增功能

### 學習紀錄
- 完成次數
- 完成單字總數
- 實際學習天數
- 本輪單字進度
- 最近完成日期

只有完整完成 5 個單字時，才會增加完成紀錄。
中途關閉不會計入完成次數。

### 單字搜尋
- 可搜尋英文單字
- 可搜尋中文意思
- 可搜尋英文與中文例句
- 搜尋結果可直接播放單字與例句發音

## 保留原有功能
- 每次學習 5 個單字
- 同一輪優先避免重複
- 單字與例句發音
- 快速切換時取消上一段語音
- 手機可縮放

## 安裝方式
1. 保留原本的 `words_8A.js`。
2. 用這個資料夾內的 `index.html` 覆蓋專案原本的 `index.html`。
3. 將修改 commit 並 push 到 GitHub。
4. 等 GitHub Pages 更新後重新整理網站。

學習紀錄儲存在瀏覽器 localStorage。
換瀏覽器、換裝置或清除網站資料後，紀錄不會自動同步。
